## 8. Pointer-click implementation audit

- Schema definition: `TutorialPointerClickActionV1` in `src/tutorial/types.ts`.
- Serialized shape:
  ```json
  {
    "type": "pointer-click",
    "locator": { "kind": "test-id", "testId": "pointer-surface" },
    "position": { "x": 0.25, "y": 0.25 },
    "coordinateSpace": "fraction",
    "timeoutMs": 5000
  }
  ```
- Validation rules: enforces `type`, `locator`, `position` (fraction `[0, 1]`), `coordinateSpace: "fraction"`, optional `timeoutMs`. Closed key validation rejects extra keys.
- Geometry: `resolveTutorialFractionPoint` in `src/tutorial/tutorialPointerGeometry.ts` multiplies fraction `(x, y)` by bounding box `(width, height)` and adds box origin `(x, y)`.
- Runtime execution: `src/tutorial/tutorialActions.ts` calls `locator.waitFor({ state: "visible" })`, retrieves bounding box, resolves coordinates, calls `page.mouse.move(resolved.x, resolved.y)`, `page.mouse.down()`, `page.mouse.up()`.
- Synthetic cursor: `tutorialSession.ts` places cursor overlay at the resolved position and triggers `showTutorialClickFeedback`.

## 9. Pointer-drag implementation audit

- Schema definition: `TutorialPointerDragActionV1` in `src/tutorial/types.ts`.
- Serialized shape:
  ```json
  {
    "type": "pointer-drag",
    "locator": { "kind": "test-id", "testId": "pointer-surface" },
    "from": { "x": 0.2, "y": 0.25 },
    "to": { "x": 0.8, "y": 0.75 },
    "coordinateSpace": "fraction",
    "timeoutMs": 5000
  }
  ```
- Validation rules: enforces `type`, `locator`, `from` (fraction `[0, 1]`), `to` (fraction `[0, 1]`), `coordinateSpace: "fraction"`, optional `timeoutMs`. Rejects zero-length drags (`from.x === to.x && from.y === to.y`). Closed key validation rejects extra keys.
- Runtime execution: `src/tutorial/tutorialActions.ts` resolves start and end coordinates from the element bounding box, calls `page.mouse.move(start.x, start.y)`, `page.mouse.down()`, `page.mouse.move(end.x, end.y, { steps: 8 })`, `page.mouse.up()`.
- Error cleanup: `runWithMouseDown` uses a `try / finally` block wrapping `page.mouse.up()`, guaranteeing release of the mouse button if an intermediate movement throws.
- Synthetic cursor: `tutorialSession.ts` places cursor overlay at start position and moves cursor overlay to end position upon action completion.
