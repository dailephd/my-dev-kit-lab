## Metric formula consistency

Each documented formula was taken from the analysis owners and cross-checked: tri-state conjunction for `taskSuccess`, check-complete requirement for pass rates, `editScopePrecision` as allowed-scope changes over changed files, `relativeChurn` as churn over baseline text lines, `repairSucceeded` as initial false and final true, `repairSuccessRate` over repair-attempted evaluable cases, rate denominators over determinate verdicts only, aggregate means over matched cases, and paired differences as `context-pack` minus `raw-full-file`. `statisticalEffect` is always `not-assessed`.

## Command and flag consistency

Documented options are exactly the plugin's accepted set: `--experiment`, `--out`, `--case`, `--benchmark-project`, `--kit-command`, `--agent`, `--include-real-agents`, `--timeout-ms`, `--repair-attempts`. `--agents` is not an alias; `--target`, command templates, and campaign flags are rejected. Observed rejections: `--timeout-ms` without real mode; `--timeout-ms` above 1800000; `--repair-attempts 3`; `--agent` without `--include-real-agents`; `--agents`; `--target`. Default timeout 240000 ms, maximum 1800000 ms; repairs 0, 1, or 2 with at most three attempts per treatment. A deterministic run exits `0` and writes `report.json`, `report.html`, `report.txt`, the execution and analysis artifacts, and `diffs/`.

## Known limitations preserved

1. Live Codex/Claude repair behavior has not been validated through a paid real-provider campaign.
2. POSIX execution of the newest agent-success tests and the deep-path correction tests is pending.
3. The plugin implements recursive glob matching locally without changing the older shared `fileGlobs` matcher.
4. Long Windows output paths can still produce a controlled infrastructure failure.
5. Generic self-target report metadata may contain absolute machine-local paths.
6. Provider telemetry can be unavailable.
7. Deterministic-fixture results do not measure context effectiveness.
8. The six-task corpus is finite and controlled.
9. No automatic treatment winner or significance claim is produced.
10. Generalized campaign resume and scheduling are not part of v0.9.0.
