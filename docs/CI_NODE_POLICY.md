# Node validation and CI policy

The my-dev-kit ecosystem uses **latest stable Node.js locally** and a nonduplicated **Node 24** hosted baseline on Ubuntu, macOS, and Windows. Local `npm run validate:local` verifies the actual Node version against the official [Node.js release index](https://nodejs.org/dist/index.json), then runs docs, typecheck, the full suite, `verify` (the one build plus benchmark checks), and packed-package acceptance. Run `npm ci` first. The version checker does not install Node, and fails closed without network access. During corrections use only focused local tests until a final validation is needed.

GitHub [CI](../.github/workflows/ci.yml) uses three Node 24 cells, one per OS. Each performs docs and typecheck, runs `verify` once (which builds), then the full regression suite once and the packed-package verifier. The standalone browser and focused bridge tests were removed as separate steps because both are already in the complete Vitest suite. Do not run an additional build before `verify`.

The old `pre-release-latest-node-readiness.yml` duplicated the complete suite on newer Node versions and has been retired. Unique code-rot and security validation remain separate local readiness responsibilities, including candidate-specific approvals for reviewed intentional network operations; their original raw scanner results must be preserved. Do not treat a previously accepted exception as scanner PASS or silently transfer it to a changed candidate. Hosted [CodeQL](../.github/workflows/codeql.yml) stays independent and covers JavaScript/TypeScript and Actions; it runs on main pushes and PRs to main, and supports manual dispatch for candidate branches. Release-branch pushes do not themselves repeat the complete CI matrix; create a release PR or dispatch the main CI workflow when explicitly required.

PR and subsequent main runs are separate release identities. Never dispatch duplicate full-suite runs for the same OS/Node/candidate. Keep implementation corrections focused, and do not run paid Codex/Claude campaigns as general release gates.
