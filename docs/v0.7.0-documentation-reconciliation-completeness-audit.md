## 4. Authoritative implementation facts

The implementation owners and tests establish these facts:

- `src/experiments/defaultRegistry.ts` registers `context-window-scaling` alongside the existing three plugins. Metadata marks it experimental and self-only, with JSON, text, HTML, and plot outputs.
- `context-window-scaling` uses exactly `raw-full-file` and `my-dev-kit-guided` treatments with the bundled four-case catalog and fixed self target.
- Standard budgets are 8192, 16384, 32768, and 65536 estimated tokens. Custom positive safe integers are supported. Budgets are sorted; duplicate values after normalization are rejected.
- Each treatment context is constructed once, independently of the budgets. Context is not truncated or rebuilt per budget, and the budget is not passed to the retrieval owner or evaluator.
- Estimated tokens use `ceil(characters / 4)`. Fit uses `estimatedTokens <= budget`; utilization is uncapped and may exceed 100 percent.
- The deterministic fake-agent evaluator runs no more than once per treatment and its result is shared by budget cells where the context fits. Its correctness evaluation is context-independent in this harness.
- A `context-too-large` cell is an available unsuccessful outcome, not an operational execution failure. Correctness is unavailable for that cell; it remains in the success-rate denominator. Operational/evidence-unavailable cells are unavailable and excluded from that denominator.
- Omitted relevant-file evidence compares benchmark expected files with the observed context provenance. It does not calculate retrieval precision, recall, or irrelevant-context ratio.
- The plugin writes `context-window-scaling-execution.json` (execution schema `my-dev-kit-lab-context-window-scaling-execution-v1`) without context text. JSON, text, and HTML reports present bounded evidence.
- The existing `plots generate` route reads and validates the execution artifact and generates exactly three plot IDs: `context-window-scaling-context-size`, `context-window-scaling-success-rate-by-budget`, and `context-window-scaling-correctness-by-budget`.
- When a directory contains both context-window-scaling and warm-index evidence, plot generation fails as ambiguous; it does not apply a precedence rule. Other directories without those plugin sources use the legacy controlled-experiment plot path.
- The plugin has no external-target support, real-agent campaign, dedicated screenshot/gallery integration, or synthetic-repository generator. Synthetic generation remains planned for v0.7.1.
